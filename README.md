Nettside for bruktbuikken på merkatå. Utviklet av Josef Burkan og Kenny Vo

Nettsiden:
https://merkata-bruktbutikk.vercel.app

Har et enkelt og behagelig design. Kunder kan lese om butikken, samt se på og filtrere produkter som ligger inne. 

Administrator kan i tillegg legge inn, redigere og slette produkter etter behov. 

Bygget med Next.JS, Supabase og Cloudinary
